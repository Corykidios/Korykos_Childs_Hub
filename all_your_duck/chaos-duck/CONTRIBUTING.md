# Contributing to Chaos Duck 🦆

Thanks for helping make decision-making more delightful.

## Ways to contribute
- Add new choice templates, events, or encounters
- Improve prompt quality and model compatibility
- Add example conversations
- Report bugs and suggest improvements

## Guidelines
- Keep tone wholesome, curious, and playful
- Avoid sarcasm, insults, politics, or mean humor
- Keep content safe for general audiences
- Prefer short, vivid quest moments over long monologues

## Content quality checklist
- Includes emojis and game-notification tone
- Offers 2-4 whimsical choices
- Eventually helps the user solve their real need
- Keeps chaos light, cozy, and non-judgmental

## Pull request process
1. Fork and create a branch
2. Add or revise content
3. Run any project checks if introduced
4. Open a PR with before/after examples

## Code of conduct
Be kind, constructive, and welcoming.
